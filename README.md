# RIMs Transport — AI-Managed Email Security Dashboard

A client-facing demonstration dashboard for RIMs Transport (adapting-services.ca) showing an
AI-managed email security service built on **Microsoft Defender for Office 365 Plan 2**:

- Microsoft 365 integration (Defender P2, Exchange Online, Entra ID via Graph API)
- A **monitoring agent** (live activity log) and an **awareness / SAT agent**
- Results dashboard: emails blocked, threat mix, phishing click-rate, training completion, risk score

> Illustrative demonstration data — sample values for a 50-seat tenant.

Single self-contained `index.html` (no build step). Deployed via Netlify.
